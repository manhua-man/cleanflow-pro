# CleanFlow 产品版本功能规划规范书 (Product Tier & Feature Specification)

---

## 1. 产品定位与商业化哲学

### 1.1 核心定位
CleanFlow 是面向 Windows 平台的轻量级原生桌面中枢，深度融合了两大核心支柱：
1. **全盘毫秒检索与资产中枢**（吸收 Listary Pro、fsearch 的 MFT 裸盘秒搜、对话框穿透与智能动作中枢能力，并针对大众用户补齐拼音检索与可视化分类药丸）；
2. **磁盘空间深度治理与系统瘦身引擎**（对齐 CCleaner、TreeSize、SpaceMonger 的深度清理与可视化分析，并提供独家底层 Junction 搬迁、ReFS 块克隆与进程解锁黑科技）。

### 1.2 商业化分级原则
- **免费社区版 (Community / Free Edition)**：
  - **原则：纯净克制、零广告骚扰、大众易用性拉满、基础体验完整**。
  - 核心秒搜能力必须对大众极度友好（内置汉字拼音声母检索、可视化类型过滤药丸、1-Edit拼写容错、最近文件历史与搜索词记忆），满足普通用户日常文件定位与基础系统清理，筑牢装机量与良好口碑。
- **专业商业版 (CleanFlow Pro Edition)**：
  - **原则：痛点驱动、效率杠杆、底层黑科技与深度自动化**。
  - 针对开发者、极客、设计师与 IT 管理员，提供系统底层黑科技特权（ReFS 零拷贝块克隆、NTFS Junction 跨盘热搬迁、Restart Manager 进程死锁穿透）、极客工作流穿透（Quick Switch 对话框无限制穿透、双击 Ctrl 底层钩子、3-Gram 源码千万行 Grep、RegEx 流式检索、开发者生态网络直达、目录收藏短别名、自定义动作与排除项配置）以及全天候静默自动化守护。

## 3. 功能分级详细定义与边界约束

### 3.1 全盘毫秒检索与资产中枢 (Search & Asset Hub)

#### 免费社区版边界
- **索引与检索范围**：支持全盘所有 NTFS 卷的 MFT 流式读取与常驻索引；
- **汉字拼音与声母全拼检索**：内置轻量拼音词库，支持汉字全拼与声母首字母缩写双向命中；
- **可视化类型过滤药丸 (Filter Chips)**：在搜索框下方常驻显示 `[全部]`、`[文件夹]`、`[文档]`、`[图片]`、`[视频]`、`[音乐]`、`[压缩包]`、`[应用]` 药丸按钮，点击一键过滤；
- **容错匹配**：支持 1-edit Damerau-Levenshtein 英文与字符拼写容错；
- **历史记录**：支持记录最近打开的 30 项文件资产，并在空白搜索框按上下方向键翻看近期查询词；
- **基础动作**：支持在资源管理器中定位、复制绝对路径、复制目录、默认应用打开。

#### 专业版 (Pro) 专属边界
- **双击 Ctrl 全局底层钩子**：挂接 Windows 低级键盘钩子，连续双击 Ctrl 快速唤醒搜索框，与系统任意前台窗口无缝融合；
- **目录收藏夹与短别名 (Favorites & Aliases)**：支持对任意深层工作目录添加星标收藏，并自定义简写别名（如定义 `prj` 别名直达 `D:\Workspace\Projects`）；
- **自定义动作 GUI 编辑表单**：提供图形化配置界面，允许用户自由添加外部工具程序、设置图标并配置 `{path}` `{dir}` 等宏参数；
- **图形化排除规则管理器**：提供直观的黑白名单管理面板，支持使用通配符与正则表达式排除特定干扰目录；
- **Quick Switch 对话框穿透**：系统级自动识别 `#32770` 通用文件对话框，秒级自动穿透注入路径；
- **开发者网络与生态直达**：原生内置 `gh`, `cargo`, `npm`, `so`, `py`, `docker` 等快捷前缀；
- **指令与系统别名执行器**：支持 `cmd:`, `wt:`, `code:` 以及 `calc`, `taskmgr`, `cleanmgr` 等秒开；
- **开发者智能降噪盾牌**：下沉屏蔽 `node_modules`、`.git`、`target` 等百万级干扰项，工程工作区核心源码 +25 分置顶；
- **3-Gram 源码全文 Grep**：支持全盘工程代码全文毫秒级正则检索与符号定位；
- **RegEx 流式检索模式**：支持 `regex:^pattern$` 复杂表达式匹配。

### 3.2 磁盘空间治理与深度瘦身 (Disk Purge & Optimizer)

#### 免费社区版边界
- **WinApp2.ini 规则扫描**：完整搭载社区 6000+ 清理规则库，支持浏览器缓存、临时文件、系统日志等常规垃圾分析与清理；
- **空间透视**：支持 12x6 交互式热力树状图 (Treemap) 和巨型文件 (Giant Files) 快速透视；
- **重复文件扫描**：基于 Blake3 哈希与稀疏分块比对，找出完全一致的冗余文件，支持常规移动到回收站或直接删除。

#### 专业版 (Pro) 专属边界
- **零拷贝 Block Clone 块克隆去重**：利用 Windows ReFS / Dev Drive 的 `FSCTL_DUPLICATE_EXTENTS_TO_FILE` 机制，0 物理空间开销瞬间共享数据块去重；
- **NTFS 跨盘 Junction 软链接无损迁移**：针对 C 盘已被 Docker 数据、Node 缓存、Android SDK 挤爆的痛点，提供一键跨盘迁移并自动构建透明 NTFS Reparse Point / Junction，软件零感继续运行；
- **进程死锁穿透解锁 (Process Unlocker)**：基于 Win32 Restart Manager API，精准定位锁定目标文件的具体进程，提供无损断开连接或安全终止进程；
- **注册表幽灵死链与孤立项深度治理**：深度扫描已卸载软件在注册表中遗留的无主键值与失效 COM 组件，提供一键治理与注册表增量快照备份（支持损坏一键回滚）。

---

### 3.3 自动化、静默守护与系统集成 (Automation & Daemon)

#### 免费社区版边界
- 纯本地手工触发模式，用户打开界面并点击开始后执行扫描与治理；关闭程序后不常驻后台。

#### 专业版 (Pro) 专属边界
- **CleanFlow 守护进程 (Background Daemon)**：低内存常驻（占用 < 12MB RAM），全天候静默守护；
- **智能磁盘水位阈值预警**：当系统卷可用空间低于预警阈值时，自动触发增量治理策略；
- **定时无人值守自动清理调度**：支持配置每日/每周指定时段执行静默系统瘦身与死链清理。

## 5. 实施时间线与演进路线 (Roadmap)

1. **Phase 1 (已完成)**：全量吸收 Listary 与 fsearch 核心底座（MFT 裸盘秒搜、双击 Ctrl 键盘钩子、Quick Switch 对话框穿透、1-Edit 容错、Smart Action Hub 工具嗅探、多列内存正逆序排序、Pro 离线授权体系）。
2. **Phase 2 (即刻启动：大众高频易用性专项)**：
   - **汉字拼音首字母检索**：集成轻量级拼音词库，支持中文声母缩写（如 `jsq` 搜计算器）与全拼即时匹配；
   - **可视化类型过滤药丸 (Filter Chips)**：在主界面与 Spotlight 悬浮窗增加 Fluent 风格分类药丸按钮（`全部`、`文件夹`、`文档`、`图片`、`视频`、`音乐`、`压缩包`、`应用`），并在后端完善宏扩展名集合映射；
   - **历史记忆流**：实现最近打开文件历史与搜索框上下键翻看近期查询词。
3. **Phase 3 (Pro 资产管理与高级定制)**：
   - 目录收藏夹管理与短别名绑定；
   - 自定义外部动作 GUI 可视化编辑表单；
   - 图形化通配符与正则排除规则管理器。
4. **Phase 4 (正式商业化发布)**：
   - 构建 Inno Setup 独立离线安装包；
   - 上线官网与多版本功能对比引导闭环。
