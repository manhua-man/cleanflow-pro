# CleanFlow 产品版本功能规划规范书 (Product Tier & Feature Specification)

---

## 1. 产品定位与商业化哲学

### 1.1 核心定位
CleanFlow 是面向 Windows 平台的轻量级原生桌面中枢，深度融合了两大核心支柱：
1. **磁盘空间深度治理与系统瘦身引擎**（对齐 CCleaner、TreeSize、SpaceMonger 的深度清理与可视化分析能力）；
2. **全盘毫秒检索与资产中枢**（对齐并吸收 Listary Pro、fsearch 的 USN/MFT 流式秒搜、对话框穿透与动作流水线能力）。

### 1.2 商业化分级原则
- **免费社区版 (Community / Free Edition)**：
  - **原则：纯净克制、零广告骚扰、基础体验完整**。
  - 核心功能必须足够强劲，满足普通电脑用户和轻度开发者的日常文件秒搜、系统常规缓存清理、重复文件扫描等核心诉求，建立庞大且坚固的口碑与装机量壁垒。
- **专业商业版 (CleanFlow Pro Edition)**：
  - **原则：痛点驱动、效率杠杆、底层黑科技与深度自动化**。
  - 针对高级软件工程师、IT 管理员、资深极客和效率强迫症用户，提供系统底层黑科技特权（ReFS 零拷贝块克隆、NTFS Junction 跨盘热搬迁、Restart Manager 进程死锁穿透）、极客工作流穿透（Quick Switch 对话框穿透、双击 Ctrl 底层钩子、3-Gram 源码 Grep、RegEx 流式检索、开发者网络与终端直达）以及全天候静默自动化治理。

## 3. 功能分级详细定义与边界约束

### 3.1 全盘毫秒检索与资产中枢 (Search & Asset Hub)

#### 免费社区版边界
- **索引与检索范围**：支持全盘所有 NTFS 卷的 MFT 流式读取与常驻索引；
- **匹配能力**：支持精确匹配、前缀匹配、后缀匹配与 1-edit 拼写容错纠错；
- **交互方式**：支持通过 Alt+Space 快捷键唤出 Spotlight 悬浮窗，支持主界面数据网格实时检索；
- **动作执行**：支持基础动作（资源管理器中定位、复制路径、默认应用打开）。

#### 专业版 (Pro) 专属边界
- **双击 Ctrl 全局底层钩子**：挂接 Windows 低级键盘钩子，连续双击 Ctrl 快速唤醒搜索框，与系统任意前台窗口无缝融合；
- **Quick Switch 对话框穿透**：当用户在任何第三方软件（浏览器另存为、Office 打开、Photoshop 导出等）打开 `#32770` 通用文件对话框时，CleanFlow Pro 自动检测并允许一键注入路径，无需重复翻找目录；
- **开发者网络与生态直达**：原生内置 `gh` (GitHub), `cargo` (Crates.io), `npm`, `so` (StackOverflow), `py` (PyPI), `docker` (DockerHub) 等快捷前缀，回车毫秒穿透浏览器；
- **指令与系统别名执行器**：支持 `cmd: <command>`、`wt: <dir>`、`code: <path>` 以及 `calc`, `taskmgr`, `cleanmgr` 等系统别名极速唤起；
- **智能降噪盾牌与工程工作区优先**：针对大型项目工程，自动识别并下沉屏蔽 `node_modules`、`.git`、`target`、`.venv`、`__pycache__` 等百万级碎文件干扰，并将工作区核心源码赋以 +25 分置顶展示；
- **Trigram 3-Gram 全文源码 Grep**：支持全盘工程代码全文毫秒级正则检索与符号定位；
- **RegEx 流式检索模式**：支持 `regex:^pattern$` 复杂表达式匹配。

---

### 3.2 磁盘空间治理与深度瘦身 (Disk Purge & Optimizer)

#### 免费社区版边界
- **WinApp2.ini 规则扫描**：完整搭载社区 6000+ 清理规则库，支持浏览器缓存、临时文件、系统日志等常规垃圾分析与清理；
- **空间透视**：支持 12x6 交互式热力树状图 (Treemap) 和巨型文件 (Giant Files) 快速透视；
- **重复文件扫描**：基于 Blake3 哈希与稀疏分块比对，找出完全一致的冗余文件，支持常规移动到回收站或直接删除。

#### 专业版 (Pro) 专属边界
- **零拷贝 Block Clone 块克隆去重**：利用 Windows ReFS / Dev Drive 的 `FSCTL_DUPLICATE_EXTENTS_TO_FILE` 机制，在不额外占用 1 字节物理空间的前提下，将完全相同的巨型模型或文件瞬间共享数据块，实现零空间损耗去重；
- **NTFS 跨盘 Junction 软链接无损迁移**：针对 C 盘已被 Docker 数据、Node 缓存、Android SDK、HuggingFace 模型挤爆的痛点，提供一键跨盘迁移并自动构建透明 NTFS Reparse Point / Junction，软件零感继续运行；
- **进程死锁穿透解锁 (Process Unlocker)**：基于 Win32 Restart Manager API，精准定位锁定目标文件或目录的具体进程，提供无损断开连接或安全终止进程，彻底终结“文件正在使用无法删除”的顽疾；
- **注册表幽灵死链与孤立项深度治理**：深度扫描已卸载软件在注册表中遗留的无主键值、失效 COM 组件、空自启项，提供一键治理与注册表增量快照备份（支持损坏一键回滚）。

---

### 3.3 自动化、静默守护与系统集成 (Automation & Daemon)

#### 免费社区版边界
- 纯本地手工触发模式，用户打开界面并点击开始后执行扫描与治理；
- 关闭程序后不常驻多余后台资源。

#### 专业版 (Pro) 专属边界
- **CleanFlow 守护进程 (Background Daemon)**：低内存常驻（占用 < 12MB RAM），全天候静默守护；
- **智能磁盘水位阈值预警**：当系统卷可用空间低于预警阈值（如 10%）时，自动触发增量治理策略；
- **定时无人值守自动清理调度**：支持配置每日/每周指定时段执行静默系统瘦身与死链清理。

## 5. 技术架构：PRO 门禁与无感体验设计

### 5.1 门禁设计原则
1. **绝不采用恼人的全屏弹窗或强制拦截广告**：
   - 保持 Windows 11 Fluent Design 原生质感；
   - 在 Pro 专属特性（如 Quick Switch、Junction 迁移、Block Clone、RegEx 模式、双击 Ctrl 选项）旁呈现精致优雅的 `PRO` 徽章；
   - 点击时展开半透明 Fluent 风格的特性说明与一键升级面板，提供“一键体验 7 天 Pro 试用”选项。
2. **离线安全加密激活机制**：
   - 采用现代非对称加密算法（如 Ed25519 签名体系），完全支持离线网络环境激活，绝不在后台进行侵犯隐私的上报操作；
   - 激活密钥格式设计：标准 25 字符分段码（如 `CLEAN-PRO7X-88KLM-99QWE-A1B2C`）。

### 5.2 代码层架构支撑 (Rust 后端)
在后端采用 Rust 模块化权限控制设计：
```rust
// 伪代码架构设计
pub enum LicenseTier {
    Community,
    ProLifetime { licensee: String, valid_until: Option<u64> },
    Enterprise { company: String, seats: u32 },

pub trait FeatureGate {
    fn is_pro_feature(&self) -> bool;
    fn can_execute(&self, tier: &LicenseTier) -> bool {
        match tier {
            LicenseTier::Community => !self.is_pro_feature(),
            LicenseTier::ProLifetime { .. } | LicenseTier::Enterprise { .. } => true,
        }
    }
}
```

## 6. 实施时间线与演进路线 (Roadmap)

1. **Phase 1 (当前状态)**：全量吸收 Listary Pro 与 fsearch 特性底座，确保底层性能、快捷键钩子、Quick Switch 穿透与 MFT 检索 100% 稳定运行。
2. **Phase 2 (产品规范宣贯与 UI 徽章梳理)**：在主界面与 Spotlight 悬浮窗中，建立统一规范的 Fluent `PRO` 徽章体系，完成试用期与体验链路设计。
3. **Phase 3 (授权系统接入)**：基于 Ed25519 实现轻量级离线授权校验器与激活对话框。
4. **Phase 4 (正式商业化发布)**：构建专业安装包，上线多版本对比官网与购买引导闭环。
